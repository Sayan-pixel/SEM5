## 📖 Overview
This repository contains all the academic materials, lab assignments, and project files for the 5th Semester of the B.Tech program at Indian Institute of Information Technology Guwahati (IIITG). It spans across various domains including Theory of Computation, Cloud Computing, Computer Networks, Machine Learning, Humanities, and Basic Sciences.

---

## 📂 Course Directory

### 🧮 CS301: Theory of Computation
Core computer science theory regarding automata, computation, and languages.
- **`CS301/`**: Contains the syllabus, mid-semester paper (2024), and various tutorial resources.

### 🧠 CS306: Machine Learning (Theory)
Theoretical foundations of machine learning models and algorithms.
- **`CS306/`**: Includes lecture slides on regression, correlation, iterative optimization, gradient descent, logistic regression, and neural networks.

### ☁️ CS351: Cloud Computing (Theory & Lab)
Exploration of cloud architecture, virtualization, and practical deployments.
- **`CS351/`**: Lecture materials and theory slides.
- **`CS351Lab/`**: 
  - **Lab 1**: Python Warmup and basic programming exercises.
  - **Lab 2**: AWS IAM, EC2, and Amazon S3 deployments, including a static portfolio website (`HTML/CSS/JS`).
  - **Lab 3 to 6**: Python programming assignments and web service setups.
  - **Lab 7**: AWS Elastic Beanstalk deployments.
  - *Technologies*: `Python`, `AWS (EC2, S3, Elastic Beanstalk)`, `HTML`, `CSS`, `JavaScript`

### 📡 CS352: Computer Networks (Theory)
Theoretical concepts underlying modern computer networks.
- **`CS352/`**: Contains chapter-wise lecture materials on the Physical Layer, Data Link Layer, MAC Layer, and past mid-semester papers.

### 🌐 CS353-LC3C: Computer Networks Lab
Practical implementation of networking concepts and protocols.
- **Lab 1**: Socket Programming in Java and C (Client-Server architecture).
- **Lab 2 & 3**: Network packet analysis, scripting, and advanced networking concepts.
- **Lab 4**: Error detection and correction (Hamming Code, CRC).
- **Lab 5 & 6**: Advanced topics, CSMA protocol simulations.
- **Lab 7**: MAC Sublayer assignments.
- *Technologies*: `Java`, `C`, `Python`

### 🤖 CS360: Machine Learning Lab
Hands-on machine learning, data analysis, and predictive modeling.
- **Lab 1 & 2**: Python packages manual, data visualization, and linear regression models (e.g., Salary vs. Experience).
- **Lab 3 & 4**: Advanced data analysis, non-linear relationships, plotting, and dataset variance.
- **Lab 5 to 8**: Logistic Regression, model evaluation metrics (Confusion Matrices, Cost vs Epochs), and Cross-Validation.
- *Technologies*: `Python (Pandas, NumPy, Matplotlib, Scikit-Learn)`

### 🧬 SC301: Biology
Basic science course focusing on the fundamentals of biology and life sciences.
- **`SC301/`**: Includes extensive lecture slides covering Biomolecules (Carbohydrates, Lipids, Proteins, Nucleic acids), Cell Structure & Division, DNA replication, Transcription, Translation, and Regulation of Gene Expression, along with handwritten short notes.

### 🗣️ HS302: Cognitive Science & Linguistics
Humanities elective focusing on the intersection of language, mind, and society.
- **`HS302/`**: Contains reading materials, linguistics texts, and folktale excerpts.
